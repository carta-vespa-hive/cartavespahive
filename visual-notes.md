# Visual Notes from Inspiration Image

## Key Elements
- **Fractal pyramid structures**: Nested concentric squares with pyramid peaks, creating a "wasp nest" ziggurat effect
- **Color palette**: Deep teal (#1a7a7a / #2d8a8a) with gold/amber (#d4a84a) edge outlines
- **Geometric grid modules**: Rectangular blocks arranged in cross/plus patterns, like circuit boards or hive cells
- **3D pyramids**: Wireframe-style pyramids with teal faces and gold edges, isometric perspective
- **Nested squares**: Concentric square patterns with dark void centers (black holes)
- **Scale variation**: Elements range from tiny scattered pieces to large focal structures
- **Black background**: Deep void background that makes the teal-gold geometry pop
- **Modular/fractal**: Everything looks like it could be assembled from smaller identical pieces

## Color Mapping for Three.js
- Primary surface: teal ~#1a7a7a to #2d8a8a
- Edge/wireframe: gold ~#d4a84a
- Deep void: #0a0a0a
- Accent highlights: lighter teal #4ab8b8

## 3D Model Approach
- Build pyramids as Three.js geometry with EdgesGeometry for gold wireframe
- Nested square structures as layered planes with decreasing scale
- Particle system for small scattered geometric fragments
- Fractal subdivision for the grid/hive patterns
